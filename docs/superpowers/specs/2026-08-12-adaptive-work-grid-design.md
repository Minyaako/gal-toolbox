# 画师／声优共享自适应作品网格设计

## 目标

统一画师作品列表与声优角色列表的桌面密度，消除画师页固定两列以及声优页宽屏右侧空轨道。VN 详情中的画师关系名单不在本次调整范围内。

## 设计

- `.role-grid` 与 `.artist-work-grid` 共用 `repeat(auto-fit, minmax(205px, 1fr))`。
- 使用 `auto-fit` 收起未使用的轨道，让最后一行已有卡片利用剩余宽度。
- 1500px 内容区最多自然形成六列；较窄桌面根据可用空间降为四至五列。
- 760px 以下固定两列，430px 以下固定一列，保持现有移动端卡片可读性。
- `.artist-relation-grid` 继续保持桌面两列、430px 以下一列，不受作品列表规则影响。

## 验收

- 画师页不再固定两列，并与声优页采用同一基础网格声明。
- 大窗口声优页可形成六列，且不足一整行时不保留空轨道。
- 760px 与 430px 断点分别为两列和一列。
- 现有画师备注、分页、预取和卡片交互不变。
